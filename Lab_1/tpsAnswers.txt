2. We shared our GCC references with our TPS partners and bookmarked the references.

3. The command to compile main.c is:
gcc main.c -o main

4. We know the program compiled successfully if GCC does not report errors and an executable file is created. We can also run the executable and see "Welcome to CSE 31!"

5. The -c flag compiles the source file into an object file without creating the final executable.

6. The -g flag adds debugging information to the executable.

7. To change the executable name from main to cselab1:
gcc main.c -o cselab1

8. When we type gcc main.c without specifying an executable name, GCC creates an executable named a.out by default.

9. To run the program:
./main
